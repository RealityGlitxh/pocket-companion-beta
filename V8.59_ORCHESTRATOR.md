# V8.59.3 Automatic Sync Orchestrator

V8.59.3 adds the execution layer above the V8.59.2 adapter contract and V8.59.1 ingestion pipeline.

Flow: trigger adapter -> record run -> retry transient failure -> validate adapter envelope -> normalize/deduplicate -> automatically apply ready records -> stage conflicts -> finish run history.

## Scheduling
Signed-in users can save one schedule per available adapter. The schedule stores cadence, retry policy, whether ready records may auto-apply, last/next run state, and non-secret metadata. Browser schedules execute while Pocket Companion is open and visible. The database representation is intentionally reusable by a future approved server-side integration.

## Safety boundary
The orchestrator does not add any Nintendo, Pokémon, Google, or Apple password/session-cookie handling. It invokes only adapters registered by the read-only V8.59.2 framework. The official Pocket adapter remains disabled until a verified official third-party player-data API and authorization flow exists.

## Merge behavior
Ready records may be auto-applied. Collection conflicts are staged, not silently overwritten. Duplicate Rank/Battle records are skipped. Signed-in runs and import batches keep provenance/counts without storing account credentials.
