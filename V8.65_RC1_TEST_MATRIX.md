# PocketNexus — V8.65 RC1 Test Matrix

## RC1 rule

V8.65 RC1 is under feature freeze.

For every failure:

actual failure → smallest necessary repair → rerun the same check → inspect the result → repeat until GREEN

Do not redesign, refactor, or add unrelated features during RC1 stabilization.

## RC1 blocker severity

- P0 — data loss, authentication/session loss, app cannot start, broad blank/crash loop
- P1 — major route unusable, primary workflow broken, persistent Runtime Recovery, severe responsive failure
- P2 — secondary control or layout failure with a usable workaround
- P3 — cosmetic/polish issue that does not block Closed Beta

RC1 may not advance with an unresolved P0 or P1.

## Advancement rule

When automated regression is GREEN and required physical-device checks are completed without unresolved P0/P1 blockers:

- If no release-blocking failures remain → approve V8.65 RC1 for Closed Beta.
- If a release-blocking failure is found → create the smallest RC2 hotfix set, rerun only the failed checks plus the RC1 regression baseline, then re-evaluate.
