# V8.62.1 — PWA Foundation

## Added
- Web App Manifest with standalone display, theme/background colors, app identity, icons, and shortcuts.
- 192px, 512px maskable-capable icons plus Apple touch icon.
- Service worker with versioned app-shell caching, same-origin runtime caching, offline navigation fallback, old-cache cleanup, and controlled update activation.
- Install prompt support on compatible browsers.
- iPhone/iPad Add to Home Screen guidance.
- Online/offline status notices.
- Update detection with a user-controlled Update action.
- Standalone-mode safe-area behavior.

## Boundaries
- Service workers require HTTPS (or localhost). They do not register from file:// browser tests.
- V8.62.1 is the PWA foundation. Full card database/artwork offline caching and deeper performance work remain V8.62.2.
- Supabase/cloud-dependent features still require connectivity.
- No Supabase migration is required.
