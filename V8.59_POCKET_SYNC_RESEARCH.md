# V8.59 Pocket Sync Research Gate

Research checkpoint: 2026-09-03

## Verified public facts
- Pokémon TCG Pocket supports linking save data to Nintendo Account, Google Account, and Apple Account (platform/age restrictions apply).
- Pocket exposes ranked point history inside the game at Ranked Match > (?) > Battle History.
- Nintendo supports consent-based sharing of some Nintendo Account information with approved third-party services.
- We have not verified a public third-party Pokémon TCG Pocket API that exposes a player's card collection, ranked battle history, or Pocket save data.
- The official Pokémon forum contains a request for a public authenticated Pocket collection-sync API; the moderator directs the suggestion to Pokémon Support rather than identifying an existing API.

## V8.59 rule
Automatic Pocket Sync remains disabled until a legitimate read-only source is verified. Never ask users for Nintendo/Pokémon passwords, copied cookies, or reusable game-session tokens, and do not reverse-engineer private endpoints.

## Target pipeline
Pocket save -> legitimate read-only source -> normalize -> Collection / Rank History / Battle Tracker -> provenance + sync history.
