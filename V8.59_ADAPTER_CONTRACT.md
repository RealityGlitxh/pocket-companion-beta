# V8.59.2 Pocket Sync Adapter Contract

Pocket Sync adapters isolate external data sources from PocketNexus's Collection, Rank, and Battle systems.

## Standard contract

Every runnable adapter is read-only and declares:
- `id`, `version`, source metadata, availability, and supported scopes.
- `read(context)` to obtain data through a legitimate source-specific mechanism.
- Optional `toEnvelope(raw)` when the source needs custom mapping.

Every successful adapter run returns schema `1.0` with:
- `adapter`: adapter id/version.
- `source`: key, label, kind, official flag, and `read_only: true`.
- `fetched_at`.
- `domains.collection[]`.
- `domains.rank_history[]`.
- `domains.battle_history[]`.
- non-secret `provenance` metadata.

The envelope then enters the V8.59.1 ingestion pipeline for canonical normalization, duplicate detection, conflict review, and merge.

## Security boundary

The framework rejects fields representing passwords, cookies, reusable session tokens, refresh tokens, client secrets, service-role secrets, or game-session credentials. It does not provide private-endpoint discovery or reverse engineering.

The `official_pocket_api` adapter is a disabled research placeholder. It becomes runnable only if a verified official third-party read-only Pokémon TCG Pocket player-data API and authorization flow exists.

## Included adapters

- `staged_json` — available developer/test adapter that accepts user-supplied JSON and proves the contract end to end.
- `official_pocket_api` — research-only placeholder, disabled.
