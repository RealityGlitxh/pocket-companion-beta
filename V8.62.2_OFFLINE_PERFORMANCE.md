# V8.62.2 — Offline + Performance

- Upgraded the PWA service worker to cache the canonical `cards.json` and metadata `cards.extra.json` with stale-while-revalidate behavior after the first successful online load.
- Added bounded card-art runtime caching (up to 180 Limitless images) so recently viewed artwork can reopen offline without allowing an unbounded cache.
- Preserved the existing localStorage canonical-card fallback as a second offline layer.
- Added CDN preconnect hints to reduce card-data/art connection startup cost.
- Preserved lazy thumbnail loading and async image decoding already used by the main card renderer.
- App-shell assets remain cached and versioned; old V8.62.1 caches are removed on activation.
- Offline capability is deliberately "after first successful load"; the build does not bundle a stale card database into the ZIP.
- No Supabase/database changes.
