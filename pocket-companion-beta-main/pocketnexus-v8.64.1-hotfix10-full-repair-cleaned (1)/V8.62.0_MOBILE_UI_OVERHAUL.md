# V8.62.0 — Mobile UI Overhaul

Phone-first polish pass for PocketNexus.

- Five-item bottom navigation: Home, Play, Decks, Meta, More.
- iPhone safe-area support and `viewport-fit=cover`.
- Larger touch targets and 16px mobile form controls.
- Full-width bottom-sheet More menu, modals, and global search.
- Mobile spacing/typography normalization and overflow containment.
- Collection/Deck Builder, Training, Team Ranked, Pocket Sync and table layouts hardened for small screens.
- Team Ranked result controls remain reachable above the bottom navigation.
- Existing desktop behavior and all V8.61.5 systems are preserved.

No Supabase schema changes are required for V8.62.0.
