# V8.62.3 — Mobile App Readiness

- Added app-aware deep-link routing for supported PocketNexus pages and PWA shortcuts.
- OAuth/password-recovery redirects can return to the active app page on hosted HTTPS builds.
- Added installed-app resume handling so viewport and cloud session state recover after backgrounding.
- Added Visual Viewport keyboard detection; mobile bottom navigation moves out of the way while the software keyboard is open.
- Mobile form controls use a 16px minimum font size to avoid unwanted iOS input zoom.
- Added a reusable Web Share API helper with clipboard fallback for future deck/training/profile share actions.
- Added standalone/safe-area hooks for future native wrappers and installed PWA presentation.
- Fixed the Battle Tracker manifest shortcut to route to the canonical `matches` page.
- No native iOS/Android wrapper is included yet; this version prepares the web architecture for that step.
- No Supabase migration required.
